PROMPT — FANORA MVP v1.0
Plataforma de assinatura de conteúdo para creators

OBJETIVO

Desenvolver rapidamente um MVP funcional da FANORA, uma plataforma própria de creator economy baseada em perfis de criadores, conteúdo exclusivo e assinaturas recorrentes.

A primeira versão deve ser simples, rápida, responsiva, segura e preparada para evolução futura.

IMPORTANTE:
- Não tentar implementar todos os recursos de uma plataforma madura.
- Priorizar o fluxo essencial: cadastro → perfil do creator → publicação → assinatura → acesso ao conteúdo exclusivo.
- O projeto deve ser estruturado para receber novos módulos posteriormente.
- A plataforma deve operar somente com usuários adultos e creators devidamente verificados.
- Não permitir conteúdo envolvendo menores, exploração sexual, violência sexual, conteúdo ilegal ou qualquer material proibido pela legislação aplicável.
- Criar mecanismos básicos de denúncia, bloqueio e moderação desde o MVP.

36. REGRAS IMPORTANTES
==================================================

1. Creator precisa estar verificado para monetizar.

2. Usuário precisa confirmar maioridade conforme o fluxo legal definido.

3. Conteúdo privado nunca pode ser acessado apenas alterando a URL.

4. Toda autorização deve ser validada no backend.

5. Pagamento nunca deve ser considerado aprovado apenas pelo frontend.

6. O status financeiro deve ser atualizado pelo webhook do gateway.

7. Não armazenar dados completos de cartão.

8. Conteúdo privado deve utilizar armazenamento protegido.

9. Criar logs para ações administrativas.

10. Criar mecanismos de denúncia e remoção.

- escalabilidade

- segurança
